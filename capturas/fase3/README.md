# Evidencias de la Fase 3

Esta carpeta contiene las capturas de las pruebas realizadas para la Fase 3 del proyecto.

## Evidencias

- Replica Set de tres nodos: Primary, Secondary y Arbiter.
- Replicación de registros entre nodos.
- Prueba de failover y elección de un nuevo Primary.
- Transacciones ACID: commit y rollback.
- Usuario de aplicación con permisos limitados.
- Rechazo del acceso anónimo y de operaciones no autorizadas.
